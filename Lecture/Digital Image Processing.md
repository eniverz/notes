## neighbors of pixels

按照某种空间规则, 位于某个像素周围的其他像素. 用于定义"距离", 定义是否"相邻", 也是滤波,边缘检测,图像分割等操作的基础

假设灰度图中, 一个点的坐标为 `(x,y)`, 使用 `f(x,y)` 表示在 `(x,y)` 的点的值(在灰度图中, 这个值表示亮度). e.g. `p=(12, 13)` 表示一个点的坐标, `f(p)=120` 表示这个点的亮度为120

![[CS270_2026Fall_Lecture_02.pdf#page=28&rect=634,152,842,363|100]]

如图, 假设一个中心元素p周围的元素为:
```
a b c
d p e
f g h
```

那么, 4-neighbors $N_4(p)=\{(x+1,y),(x,y+1),(x-1,y),(x,y-1)\}$ 为:
```
  b  
d p e
  g
```

对角邻居是 $N_D(p)=\{(x+1,y+1),(x+1,y-1),(x-1,y+1),(x-1,y-1)\}$:
```
a   c
  p
f   h
```

8-neighbors $N_8(p)=\{(x+1,y),(x+1,y+1),(x+1,y-1),(x,y+1),(x,y-1),(x-1,y+1),(x-1,y),(x-1,y-1)\}$ 就是周围的所有8个neighbors:
```
a b c
d p e
f g h
```

## neighborhood of pixel

- closed neighborhood 闭邻域: 包含 p 本身的邻域
- open neighborhood 开邻域: 不包含 p 本身的邻域

邻域主要有这些用途：

|用途|邻域发挥什么作用|
|---|---|
|平滑、去噪|用周围像素的均值或中位数估计中心像素|
|边缘检测|比较相邻位置的亮度变化|
|区域生长、分割|从一个像素出发，吸收符合条件的邻居|
|连通分量分析|判断哪些目标像素连在一起，统计有几个对象|
|膨胀、腐蚀等形态学操作|按局部邻域规则扩大或缩小目标区域|

## adjacency

邻接性: 位置靠近的元素, 是否属于同一个连接

首先需要定义用什么邻域, 然后定义可以连接的范围是多少. 定义邻域可以直接使用 $N_4,N_8$ 等, 定义范围使用 $V=[Val_\min,Val_\max]$ 来定义(只有数值在这个区间内的才能连接)

e.g. ![[CS270_2026Fall_Lecture_02.pdf#page=33&rect=157,59,796,198]]

这个题里面, $V=[10,17]$, 也就是说, 11->13->16 是adjacent(假设使用 $N_4$)

- 4-adjacency: $p,q\in V,q\in N_4(p)$, p和q都在范围内, 并且q是p的4-neighbor
- 8-adjacency: $p,q\in V,q\in N_8(p)$, p和q都在范围内, 并且q是p的8-neighbor
- M-adjacency: $p,q\in V, (q\in N_4(p))\text{ or }(q\in N_D(p)\text{ and }N_4(p)\cap N_4(q)\not\in V)$, p和q都在范围内, 并且: 要么q是p的4-neighbor, 要么q是p的对角邻居且不能通过 4-neighbor 连接 (保证路径的唯一性)

![[CS270_2026Fall_Lecture_02.pdf#page=39&rect=57,112,927,440]]

M-adjacency的目的是, 8-adjacency会允许局部三角连接:
```
0  A  B
0  C  0
0  0  D
```

8-adjacency允许 A->B->C (重点是 B->C) , 但是M-adjacecny不允许 B->C, path

## path

Digital path，数字路径，是一串连续相邻的像素。写成 $p_0,p_1,\ldots,p_n$

要求每一对连续像素 $p_i,p_{i+1}$ 都满足指定的邻接规则。

因此可以有四路径、八路径、m 路径。

路径长度是 $n$, 也就是移动的次数。**经过四个像素，通常是走了三步，路径长度为 3。**

若起点与终点相同，就称为闭合路径。

### Connectivity

连通性，表示能否通过一条合法路径到达

对于像素集合 $S$，如果 $p,q\in S$，并且存在一条完全位于 $S$ 中的路径连接它们，就说它们在 $S$ 中连通.

两个点可能不邻接, 但是可能通过path连通
- 邻接：能否直接走一步。
- 连通：能否通过若干步到达。

### Connected Component

就是集合中一整块互相可达的像素；不能再把集合内其他像素加进来而仍保持连通

例如：

```
1  0  0
0  1  0
0  0  1
```

取所有值为 1 的像素作为 $S$：
- 四连通：有 3 个连通分量, 每一个`1`都是独立的
- 八连通：只有 1 个连通分量, 因为可以通过对角邻接而连通
- m 连通：也只有 1 个连通分量，因为这里的对角连接满足条件

### Connected Set

如果只有一个component, 并且这个component是连通的, 那么成为 connected set

## Region

是 connected component 的一个子集.

[[#Connected Component]]要求保证最大, 但是 region 不要求是最大的连通

如果两个region的并集依然是连通的, 那么称 这两个区域"相邻"

## Boundary

内边界: $\partial_\mathrm{in}R=\{p\in R|N(p)\cap R^C\neq\emptyset\}$ 属于区域, 而且至少有一个邻居是在区域外的像素
外边界: $\partial_{\mathrm{out}}R = \{p\in R^c\mid N(p)\cap R\neq\varnothing\}$ 位于区域之外, 但是紧挨着区域的元素(邻居是区域内)

![[CS270_2026Fall_Lecture_02.pdf#page=45&rect=23,55,938,521]]

|概念|关注的问题|常见判断方式|
|---|---|---|
|Boundary，区域边界|区域内外在哪里分开？|检查区域成员关系|
|Edge，边缘|图像亮度等属性在哪里明显变化？|检查局部差分、梯度|

例如，一件条纹衣服内部有很多亮暗交替，能够产生很多边缘，但它们不都是衣服整体区域的边界。

反过来，物体与背景亮度接近时，真实物体的边界也未必能产生强烈的亮度边缘。

## Distance

**欧氏距离 Euclidean distance，是两点之间的直线距离。**

$$D_e(p,q)=\sqrt{(x-s)^2+(y-t)^2}$$

这就是平面几何中的距离。

**城市街区距离 City-block distance，也叫曼哈顿距离，只允许上下左右移动。**

$$D_4(p,q)=|x-s|+|y-t|$$

你可以想象沿着方格街道走路：横向差多少格就走多少步，纵向也是如此。

**棋盘距离 Chessboard distance，允许上下左右和对角移动，每一步都记作 1。**

$$D_8(p,q)=\max(|x-s|,|y-t|)$$

为什么取最大值？

因为走一步对角线，可以同时减少一个横向差和一个纵向差。先尽可能斜着走，剩下的再沿单个方向走。

例如，从 $p=(0,0), q=(3,2)$ 出发：

| 距离      | 结果                      | 理解方式          |
| ------- | ----------------------- | ------------- |
| $D_e$ | $\sqrt{13}\approx3.61$ | 两点间直线长度       |
| $D_4$ | $3+2=5$               | 横向 3 步、纵向 2 步 |
| $D_8$ | $\max(3,2)=3$         | 对角 2 步、横向 1 步 |

这里一个对角移动的欧氏长度是 $\sqrt2$，但在棋盘距离里只算一步，所以它们衡量的方式不同。

这也把距离和开头的邻居定义联系起来：

$$N_4(p)=\{q\mid D_4(p,q)=1\}$$
$$N_8(p)=\{q\mid D_8(p,q)=1\}$$

也就是：**四邻居是城市街区距离为 1 的位置；八邻居是棋盘距离为 1 的位置。**

[[CS270_2026Fall_Lecture_02.pdf#page=48&rect=63,68,895,427|要求一个距离函数满足]]：
- 非负，且只有同一个点到自己的距离为 0。
- 对称：从 $p$ 到 $q$ 与从 $q$ 到 $p$ 距离相同。
- 三角不等式：$D(p,q)\le D(p,z)+D(z,q)$。

这些是数学上“距离”的基本要求。

**m-distance 则直接定义为最短 m 路径的长度。**

$$D_m(p,q)=\text{从 }p\text{ 到 }q\text{ 的最短 m 路径步数}$$

## Histograms

统计每一种亮度有多少个像素. 定义是：
$$h(r_k)=n_k$$
$$p(r_k)=\frac{n_k}{MN}$$

其中，$MN$ 是图像总像素数。后者叫归一化直方图，可以理解为：随机选一个像素，它的灰度等于 $r_k$ 的概率。

它们分别满足：
$$\sum_k h(r_k)=MN,\qquad \sum_k p(r_k)=1$$

假设有一幅小图像，只有四种灰度：0、1、2、3。

```
0  0  1  1
1  2  3  3
```

它的直方图就是：

| 灰度 $r_k$ | 像素数量 $h(r_k)$ | 所占比例 $p(r_k)$ |
| ---------- | --------------- | --------------- |
| 0          | 2               | $2/8=0.25$    |
| 1          | 3               | $3/8=0.375$   |
| 2          | 1               | $1/8=0.125$   |
| 3          | 2               | $2/8=0.25$    |

## Intensity Transformation

灰度变换: $s=T(r)$
- $s$ 输出灰度
- $r$ 输入灰度
- $T$ 变换规则

对于图像的pixel, 是: $g(x,y)=T(f(x,y))$

从数学上看，若两个输入灰度相近：
$$\Delta s\approx T'(r)\Delta r$$

因此：
- $T'(r)>1$：这一段灰度差异被放大。
- $0<T'(r)<1$：这一段灰度差异被压缩。

因此这个斜率可以用于计算control point的灰度变换:
![[CS270_2026Fall_Lecture_03.pdf#page=13&rect=275,72,808,450]]

| 变换      | 公式                                     | 主要理解                     |
| ------- | -------------------------------------- | ------------------------ |
| 灰度反转    | $s=L-1-r$                              | 明暗反转                     |
| 对数变换    | $s=c\ln(1+r)$                          | 对高数值增长进行压缩，便于显示动态范围很大的数据 |
| Gamma变换 | $s=r^\gamma$ (注意, 需要先归一化到 $[0,1]$ 区间内) | 提供一种平滑、可调节的曲线            |

## Histogram Equalization

把一个灰度在原图中的“累计比例”，转换成新的亮度。里引入CDF，累积分布函数：
$$F_r(r_k)=\sum_{j=0}^{k}p(r_j)$$

它回答 图像中，灰度小于等于 $r_k$ 的像素，占多少比例？ 假设灰度小于等于 100 的像素占 70%，那么：$F_r(100)=0.7$

所以计算过程只有四步：
1. 统计每个灰度的像素数量。
2. 除以总像素数，得到概率。
3. 从低灰度向高灰度累加，得到 CDF。
4. 乘 $L-1$，取整，建立映射表。

这是一个 3 位图像，因此：$L=8,\qquad r\in\{0,1,\ldots,7\}$

沿用讲义保留两位小数的概率：

| 输入 $r$ | 概率 $p(r)$ | CDF  | $7\times\mathrm{CDF}$ | 取整后输出 |
| ------- | ---------- | ---- | ---------------------- | ----- |
| 0       | 0.19       | 0.19 | 1.33                   | 1     |
| 1       | 0.25       | 0.44 | 3.08                   | 3     |
| 2       | 0.21       | 0.65 | 4.55                   | 5     |
| 3       | 0.16       | 0.81 | 5.67                   | 6     |
| 4       | 0.08       | 0.89 | 6.23                   | 6     |
| 5       | 0.06       | 0.95 | 6.65                   | 7     |
| 6       | 0.03       | 0.98 | 6.86                   | 7     |
| 7       | 0.02       | 1.00 | 7.00                   | 7     |

最终映射：

```
输入：0  1  2  3  4  5  6  7
输出：1  3  5  6  6  7  7  7
```

**为什么理论上又说，均衡化会产生均匀分布？**

这是连续模型下的结论。设：
$$s=T(r)=(L-1)\int_0^r p_r(w)\,dw$$

求导：
$$\frac{ds}{dr}=(L-1)p_r(r)$$

在适用的连续、可逆变换条件下，根据概率密度变换：
$$p_s(s)=p_r(r)\left|\frac{dr}{ds}\right|$$

代入后：
$$p_s(s) = \frac{p_r(r)}{(L-1)p_r(r)} = \frac{1}{L-1}$$

这就得到均匀密度。

## Fourier Transform

### DFT

对于图像而言, 核心是二维DFT

DFT 定义为：
$$ F[k]=\sum_{n=0}^{N-1}f[n]e^{-j2\pi kn/N}$$
这里：
- $n$：原信号中的位置。
- $k$：频率编号。
- $F[k]$：第 $k$ 个频率的复数系数。
