## Motivation

目前主流的VLA使用 "VLM as Encoder", 如 [[2504.16054|pi0.5]] 等, VLM 仅用于提取Vision和Language的hidden state, 而连续的动作生成是由一个独立的Action Expert负责的.

虽然这种做法提高了动作执行的连贯性, 但是VLM本身的能力并没有完全发挥出来(如, 思维链, 上下文学习, prompt控制, 等等).

早期的 VLA 自回归模型(如, [[RT-2]] 等)虽然保留了VLM的生成能力, 但是按action dim进行离散化导致action sequence过长, 无法满足高频控制的要求.

因此, 本文希望使用 VLM-as-Actor, 通过结构化的动作压缩分词技术解决计算瓶颈.

## Contribution

1. 统一的cross-embodiment action codec: 通过语义对齐(如, LeftArm, RightArm, Base, ...), 将不同的结构/自由度的机器人连续动作转化为共享的离散token vocabulary. 同时, 模型可以丢弃闲置部分的token, 可以有效提高模型的生成效率
2. 基于AutoRegressive的Native [[CoT]]: 不使用外挂的推理模块, 而是使用模型内部自带的思维链能力, 在输出action token之前自回归生成子任务文本/目标边界/2D轨迹, 增强模型对新场景的泛化能力/语言指令跟随能力/long-horizon多步执行能力
3. Visual Memory: 在Vision Transformer中, 采用了分解的时空注意力机制, 让模型可以吸收过去的frame
4. 无须重训的prompt-driven behavior control: 可以在提示词中修改动词或者添加副词和空间方位约束(如, "用力推进去"), 可以直接改变robot的物理执行策略, 而不需要重新训练新的网络

## Methods

### Tokenizer

![[2608.11739v1.pdf#page=7&rect=69,567,543,734]]

首先把action分成不同的part, 如, left-arm,right-arm,left-gripper,right-gripper,torso,chassis. 不同的embodiment可能只有其中的一部分part. 对于没有这一部分part的embodiment, 使用一个token填充代表这一部分没有.

![[2608.11739v1.pdf#page=7&rect=76,657,315,725]]

然后, 针对每一个part, 首先使用 [[DCT]] 把time-domain的action转换到frequency-domain. 然后经过一个action encoder(`Conv2d(in,out,kernel=(2,1),stride=(1,1))`+TransformerBlock)得到一个 128-dim 的latent. 然后, 进行 [[2203.01941|RVQ]] (4-quantizer) 得到多个token. 最后, 使用一个action decoder重建存在的token, 不存在的part直接不重建.

会使用一个特殊的loss: consistency loss, 类似 [[2602.15397#Temporal Overlap Rate (OR)|ActionCodec 里面的Time Contrastive Loss]], 但是有一定的区别:

|对比项|GalaxeaVLA Consistency Loss|TCL（备用实现）|
|---|---|---|
|共同目标|提高动作表示的稳定性|提高动作表示的稳定性|
|正样本|原动作的轻微扰动版本|时间上相邻的动作窗口|
|约束重点|离散 token 的一致性|连续 latent 的相似性|
|优化方式|token 不一致时拉近残差|拉近正样本、推远负样本|
|负样本|不需要|需要|

### G0.5

**CoT**

G0.5可以使用原生的CoT, 不是作为一个独立的规划器, 而是嵌入到模型推理的中间输出. 可选的推理内容有:
- Subtask: 把长程任务拆解成小的子任务
- BBox: 定位任务相关物体, 并在其周围预测边界框
- Trace: 预测EndEffector在图像中的二维轨迹
- ActionHint: 生成对下一步动作有帮助的提示

好处: 让CoT的内容能够直接成为后续动作预测的context

注意, CoT是可选的, 因为CoT会拖慢模型推理的速度

**Visual Memory**

由于机器人操作常常不能只看当前一帧: 遮挡,移动,任务进度,等 信息都可能丢失, 因此需要加入一些跨帧的信息来补全. 于是仿照 [[2603.03596|MEM]] 和 [[2604.15483|pi0.7]] 制作了 Visual Encoder.

G0.5选择在已有的 [[2010.11929|ViT]] 里面插入时空注意力模块, 让历史帧在视觉编码的过程中融合. 具体做法是:
1. 把历史帧和当前帧都编码成patch embeddings
2. 时间注意力.
	1. 对同一个位置不同时间的patch做causal self-attention, 得到一个attention score $A^T_q$. 使用causal mask的原因是为了只让后面的patch看到前面的patch, 前面的patch看不到后续时间的patch. $$A^T_q[t,\tau] = \begin{cases} \frac{\exp(s_q[t,\tau])} {\sum_{u\le t}\exp(s_q[t,u])}, & \tau\le t\\[8pt] 0,& \tau>t \end{cases}$$
	2. 得到attention score之后, 与 $V^T_q$ 相乘, 得到融合了历史信息的values: $$V'=\sum_{\tau\le t}A^T_q[t,\tau]V_{\tau,q}$$
3. 空间注意力:
	1. 对同一帧里面的所有patch做self-attention, 不使用任何mask, 让所有的patch能够相互看到, 得到一个 attention score $A^S$
	2. 把得到的spatial attention score 和之前得到的历史信息Values矩阵相乘, 得到融合了时间和空间信息的结果:$$O_{t,p} = \sum_q\sum_{\tau\le t} \underbrace{A^S_t[p,q]}_{\text{空间权重}} \underbrace{A^T_q[t,\tau]}_{\text{时间权重}} V_{\tau,q}$$
4. 只取最后一帧的hidden states: `hidden_states = hidden_states.view(B, T, N, D)[:, -1]`, 然后送给VLA

类似的, 有30%的概率丢失所有历史帧信息

## Pre-training

从 Qwen3.5-2B 为VLM Backbone开始.

**Data**

使用14中不同的embodiment, 把不同的embodiment action映射到一个27-dim的布局: left-arm 9dim, right-arm 9dim, left-gripper 1dim, right-arm 1dim, torso+chassis 7dim

其他辅助数据:
- 首先把action分片并寻找关键帧, 然后使用多模态模型生成action hint, subtask和full task instruction
- 使用多模态模型和 [[SAM3]] 跟踪, 生成任务相关物体的边界框和分割掩码
- 使用FK计算end effector位置, 投影, 得到头部相机画面上的二维轨迹

**Loss**

loss使用 [[Cross-Entropy Loss]] 以及 [[2210.02747|Flow Matching]] loss. 可以都使用, 也可以只使用其中之一.

**CoT**

随机从八种CoT格式里面随机抽取一种(格式里包括不生成CoT), 子任务分解赋予较高的抽取权重.
